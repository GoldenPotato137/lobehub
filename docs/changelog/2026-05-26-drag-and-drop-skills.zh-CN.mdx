# 拖拽即用的技能与会发文件的 Bot

## 本周新东西

聊天输入变得更直接。你现在可以从右侧面板把技能直接拖到消息框里，它会变成一枚动作标签——不用再翻菜单。在句子中间输入 `/`，也会弹出包含所有已安装技能的快捷菜单，无论是内置的、来自技能市场的，还是你自己 Agent 提供的。

桌面端可以把整个文件夹拖进聊天，它会以 `@localFile` 引用的形式出现，而不是把里面的每个文件都上传一遍。

Bot 也学了新本事。Discord、Telegram、Slack、飞书、微信、LINE、QQ 现在都能收发图片、视频、语音和文件，而不只是文字——只要平台支持，你的 Agent 就能发能收。

## 其他改进

- Agent 文档浏览器支持多选删除，一次清理多个文件
- 更友好的初次体验：新建 Agent 有引导界面，发送第一条消息后才会真正创建话题
- 后续建议现在也会出现在普通对话里，不再仅限于 Agent 对话
- 新增模型：Gemini 3.5 Flash、Qwen 3.7 Max
- 桌面端现在可以预览 `.cjs`、`.mjs` 和无后缀的文本文件，不再当作二进制处理
- 创建、删除、移动话题后，话题列表的分页状态会被保留
- 设置页面更清爽——文案更清晰，入口更精简
- Windows / Linux 上从主窗口访问设置的入口已恢复正常

## 修复

- 修复 Bedrock 结构化输出与 Gemini 诊断信息相关问题
- DeepSeek 工具选择与请求处理已修正
- 统一图片 MIME 类型，避免部分提供商拒收上传
- 流式取消与提供商兜底逻辑更可预期
