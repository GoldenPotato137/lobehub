# Drag-and-Drop Skills & Bots That Send Files

## What's new this week

The chat input got more direct. You can now drag a skill from the right panel and drop it into the message box as an action tag — no menu hunting. Typing `/` in the middle of a sentence also pops up a slash menu of every skill you have installed, from built-ins to ones from the Skill Market or your own agents.

On desktop, drag a whole folder into chat and it shows up as a `@localFile` reference instead of trying to upload every file inside it.

Bots learned a new trick too. Discord, Telegram, Slack, Feishu, WeChat, LINE, and QQ can now exchange images, videos, voice messages, and files — not just text. Whatever the platform supports, your agent can send and receive.

## Other improvements

- Multi-select delete in the agent documents explorer — clean up several files in one go
- A friendlier first-time experience: a guided screen for creating your first agent, and new topics don't get created until you actually send a message
- Follow-up suggestions now show up in general chats too, not only inside agent conversations
- New models: Gemini 3.5 Flash, Qwen 3.7 Max
- Desktop now previews `.cjs`, `.mjs`, and extension-less text files instead of treating them as binary
- Topic list pagination is preserved when you create, delete, or move a topic
- Settings pages cleaned up — clearer copy, simpler entries
- Settings access from the main window works correctly on Windows and Linux again

## Fixes

- Bedrock structured output and Gemini diagnostics fixes
- DeepSeek tool choice + payload handling sorted out
- Image MIME types normalized so uploads don't get rejected by some providers
- Streaming cancel and provider fallback behave more predictably
